1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
Name: CertiHub
Type: Student Portfolio & Certification Management System
Tagline: "Elevate Your Academic & Professional Journey"

CertiHub is a modern, professional web application designed for students and 
young professionals to centralize their academic achievements. It serves as a 
digital portfolio where users can track their GPA, manage certifications, 
monitor online courses, and present a professional identity to potential 
employers or institutions.


2. WHAT THE WEBSITE DOES
--------------------------------------------------------------------------------
CertiHub acts as a "Single Source of Truth" for a student's professional growth. 
It solves the problem of scattered academic data by providing:
- A centralized dashboard for all learning milestones.
- Real-time calculation of academic performance (CGPA).
- Visual categorization of skills and platforms.
- Secure, cloud-synced storage for certificates and course records.


3. KEY ACTIONS & FEATURES
--------------------------------------------------------------------------------
A. AUTHENTICATION & SECURITY
- Secure Login/Sign-up: Users can create accounts via Email/Password or 
  use Google One-Tap for instant access.
- Private Data: Each user has a unique ID (UID) ensuring they can only access 
  and modify their own personal data.

B. OVERVIEW DASHBOARD
- Personalized Greetings: Greets users by name with their profile photo.
- Motivation System: Displays rotating motivational quotes to keep users inspired.
- Analytics: Shows a "Skill Distribution" chart based on the platforms 
  (AWS, Google, Coursera, etc.) where they earned certifications.
- Recent Wins: Highlights the most recent certifications added.

C. PROFESSIONAL IDENTITY (ID)
- Identity Management: Edit name, college, major, degree, and graduation year.
- Bio Templates: Choose from professional templates (Researcher, Tech 
  Enthusiast, etc.) to quickly build a profile.
- Social Integration: Links to GitHub and LinkedIn profiles.
- Profile Picture: Upload and preview profile images directly.

D. ACADEMIC RECORDS
- Semester Tracking: Add multiple semesters with SGPA and credit details.
- CGPA Calculator: Automatically calculates Cumulative GPA in real-time 
  as you update your records.
- Progress Visualization: Displays a large, clear GPA card for quick reference.

E. CERTIFICATIONS & COURSES
- Smart Recognition: Automatically identifies logos and color schemes for 
  over 15 platforms (Udemy, Coursera, IBM, Microsoft, etc.).
- Skill Tagging: Add tags to categorize expertise gained from each certificate.
- Verification Links: Store direct links to online credentials.
- Image Uploads: Store snapshots of certificates for visual proof.


4. HOW IT PROCESSES (TECHNICAL WORKFLOW)
--------------------------------------------------------------------------------
- Real-Time Auto-Save: The website uses an "Industry-Standard Debounce" system. 
  When you type in your profile or academics, it waits 1-1.5 seconds after you 
  stop typing before automatically pushing changes to the cloud.
- Cloud Synchronization: Powered by Firebase Firestore, all data is synced 
  instantly. If you log in from a different device, your data is already there.
- Dynamic UI: Built with React, the interface updates components instantly 
  without page refreshes when data is added or deleted.
- Platform Detection: Logic in the code scans the "Issuer" field and 
  automatically applies the correct brand colors and icons (e.g., orange for 
  AWS, blue for Google).


5. TECH STACK (TOOLS & WEBSITES USED)
--------------------------------------------------------------------------------
CertiHub was created using a modern "MERN-like" stack optimized for speed:

A. CORE DEVELOPMENT
- React 18: The powerhouse framework for building the user interface.
- Vite: The build tool that makes the website load lightning-fast.
- Javascript (ES6+): The logic driving the entire application.

B. BACKEND & CLOUD
- Firebase Firestore: A NoSQL database used to store all user data in the cloud.
- Firebase Auth: Handles secure user sign-in and session management.

C. DESIGN & STYLING
- Custom CSS3: Advanced styling including "Glassmorphism" effects, 
  responsive layouts, and smooth animations.
- Lucide Icons: For professional, clean iconography throughout the site.

D. INFRASTRUCTURE
- GitHub: Used for version control and code hosting.
- Vercel: The professional hosting platform where the live website resides.
- Google OAuth: The bridge used for the "Sign in with Google" feature.
